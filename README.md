# GraphBench Challenge

Projet réalisé dans le cadre du Master 1 MIAGE – Université Paris Nanterre.

## Contenu du projet

### Partie 1

* génération de graphes
* calcul d’invariants
* Beam Search
* mutations locales
* recherche de contre-exemples

Dossier :
`graphbench-project-partie-01`

---

### Partie 2

* approche inspirée de FunSearch
* benchmark automatique
* heuristiques évolutives
* optimisation de recherche
* export des résultats CSV

Dossier :
`graphbench-project-partie-02`

---

## Technologies utilisées

* Python
* NetworkX
* NumPy
* Pandas
* Matplotlib

---

## Résultats

Le système parvient à réfuter automatiquement les conjectures du benchmark fourni.
